# NEXUS X2 — Landing Page Conceitual

Landing page de produto inspirada no ritmo visual e na organização de páginas premium de consoles, com identidade original.

## Recursos
- Cabeçalho fixo + subnavegação
- Hero responsivo com mockup do console feito em CSS
- Seções de display, dock, controles e performance
- Animações de entrada por IntersectionObserver
- Parallax leve no hero
- Tabs interativas para modos de jogo
- Modal de apresentação
- Acordeão de especificações
- Layout responsivo para desktop, tablet e celular
- Suporte a `prefers-reduced-motion`

## Como abrir
Abra `index.html` diretamente no navegador.

Também é possível servir a pasta com qualquer servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura
- `index.html`
- `css/style.css`
- `js/script.js`

## Observação
Projeto conceitual independente, sem uso de assets oficiais e sem afiliação à Nintendo.
